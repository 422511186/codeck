# 术语表

> 本表对应项目记录存储边界 ADR。

| 术语 | 定义 |
| --- | --- |
| 工作区 | 后端可访问并通过 `CODEX_WEB_WORKSPACE_ROOTS` 校验的文件系统目录，以 `cwd` 路径标识。 |
| 项目记录 | 首屏项目列表中的一条元数据记录，包含项目 ID、显示名称、工作区路径和使用时间；不包含目录文件内容。 |
| 客户端存储 | 当前浏览器的 `localStorage`。只在该浏览器可见，不跨设备同步。 |
| 服务端存储 | 后端持久化的项目记录目录，以后端实例为共享范围，能够被登录同一实例的设备读取。 |
| 仅客户端项目 | 存储位置属性为客户端的项目记录；其可见范围限于当前浏览器。 |
| 服务端项目 | 存储位置属性为服务端的项目记录；登录同一后端实例的设备共享该记录，不提供用户级隔离。 |
| 权威存储 | 某条项目记录唯一允许持久化和修改的位置。客户端项目以 `localStorage` 为权威，服务端项目以服务端项目目录为权威。 |
| 合并项目列表 | 项目页把分别读取的客户端项目和服务端项目组合为一个内存视图；该视图本身不是第三份持久化数据。 |
| 存储位置移动 | 保持项目 ID 不变，把记录先写入目标存储、成功后再从源存储删除的状态迁移。它不创建两份项目记录。 |
| 默认项目存储位置 | 由服务端持久化、通过 Web 设置页面修改的实例级设置。初始值为服务端；它只用于初始化新增表单，不直接移动已有项目。 |
| 显式迁移 | 用户在项目管理页面主动执行存储位置移动；升级或首次加载不会自动把客户端记录上传到服务端。 |
| 路径唯一性 | 同一个规范化工作区路径在客户端项目与服务端项目的合并目录中最多出现一次。 |
| 路径冲突 | 同一路径同时存在客户端和服务端记录的状态，必须由用户选择保留哪一条或取消处理。 |
| 项目目录 revision | 服务端项目目录用于乐观并发控制的整体版本号。人工修改请求携带已读取 revision，过期请求不得覆盖最新目录；`lastUsedAt` 单调更新不递增 revision。 |
| 全局最近使用时间 | 服务端项目在任一设备被进入时更新的共享 `lastUsedAt`；并发更新只保留较晚值。 |
| 部分降级 | 服务端项目目录失败时保留客户端项目功能，同时明确禁用依赖服务端目录的操作并提供重试。 |
| 移除项目 | 只从其权威存储删除项目记录，不删除工作区目录、文件或 Codex 会话。 |
